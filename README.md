# 🏆 Club de Programación Competitiva PUCV

**Resolvemos problemas · Aprendemos algoritmos · Competimos en el ICPC**

</div>

## 📌 ¿Qué es esto?

Este repositorio es el **material de estudio oficial** del Club de Programación Competitiva de la Pontificia Universidad Católica de Valparaíso. Aquí encontrarás teoría, ejercicios resueltos, plantillas y recursos para aprender a resolver problemas algorítmicos y prepararte para competencias como el **ICPC**.

El club se mueve en tres pilares:

- **Resolver ejercicios** — práctica constante para pensar mejor.
- **Hacer comunidad** — aprender en conjunto, sin importar el nivel.
- **Competir** — representar a la PUCV en torneos de programación.

---

## ¿Cómo empezar?

Si recién llegas, sigue este orden:

1. **Crea tu cuenta en Codeforces**
2. **Configura tu entorno y plantilla base** 
3. **Revisa la ruta de estudio** 

> 💡 Puedes llegar sabiendo **cualquier lenguaje de programación**, pero todo el material está en **C++**. Te acompañamos para que lo aprendas.

## 🗂️ Estructura del repositorio

| Carpeta | Contenido |
|---|---|
| 00-empieza-aqui | Primeros pasos: cuenta de Codeforces, configuración del entorno y ruta de estudio |
| 01-introduccion-cpp | Sintaxis básica, entrada/salida rápida y STL |

| 06-ejercicios-de-aplicacion | Ejercicios para reforzar cada contenido visto |
| 07-plantillas-y-snippets | Plantilla base `.cpp` y biblioteca de código reutilizable |

| 09-recursos | Libros, sitios y enlaces recomendados |

## 🎯 ¿A quién está dirigido?

El club está **abierto a todos**. Solo para orientarte según tu nivel:

- ✅ Si ya cursaste **Análisis y Diseño de Algoritmos**, tienes la base ideal para partir de inmediato.
- ✅ Si aún **no cursas Estructura de Datos**, igual eres bienvenido/a: solo te pedimos **compromiso de estudio autónomo** para nivelar los fundamentos. Te apoyamos con recursos.

No hay preguntas tontas: aquí todos aprendemos.

---

## 🏁 Simulacros y competencias

- Nuestro objetivo principal es el **ICPC** y competencias de prestigio universitario.
- Realizamos **simulacros presenciales** aproximadamente una vez al mes.
- Cada simulacro queda guardado en *08-simulacros* para que quien no pudo asistir también practique.

---

## ¿Quieres aportar material?

Si eres parte del club y quieres subir una solución o apunte, sigue estas convenciones para mantener el repo ordenado:

- Guarda cada solución en la carpeta del **tema** correspondiente.
- Nombra los archivos **sin tildes ni espacios**, usando guiones (ej: `dijkstra-camino-minimo.cpp`).
- Incluye al inicio de cada solución un **comentario de cabecera** con:

```cpp
// Problema : <nombre del problema>
// Link     : <url de Codeforces>
// Rating   : <ej. 1200>
// Idea     : <idea clave de la solución en una línea>
```
